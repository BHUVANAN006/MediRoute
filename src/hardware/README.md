# MediRoute Robot Hardware

This folder contains the Arduino source code for the MediRoute autonomous medical supply delivery robot.

## Main Controller

- Arduino UNO

## Sensors

- IR line/path sensor
- IR obstacle detection sensor
- Zone selection inputs

## Actuators

- DC geared motors
- Motor driver

## Display

- 16×2 I2C LCD Display

## Robot Functions

- Zone selection
- Line/path-based navigation
- Obstacle detection
- Automatic motor control
- Forward and reverse movement
- Left and right turning
- Destination detection
- Return-to-home operation
- LCD status display

## Source Code

The main Arduino program is:

`MediRoute_Robot.ino`

The program controls the robot's navigation, zone selection, obstacle detection, motor movement, and LCD status information.
