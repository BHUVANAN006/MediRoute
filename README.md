# MediRoute
### Autonomous Medical Supply Delivery Robot for Hospitals

MediRoute is an autonomous indoor medical supply delivery robot designed to transport medicines from a central Medication Room to predefined hospital destinations such as ICUs, wards, the OP Room, and the Operation Theatre.

The system combines line-following navigation, IR-based obstacle detection, destination selection, and a web-based medicine request system to support organized indoor medical supply delivery.

---

## 📌 Project Overview

In hospitals, medicines and medical supplies often need to be transported between departments. MediRoute is developed as a prototype solution for automating this movement along predefined indoor routes.

The robot receives a delivery destination, carries the required medicine in its storage compartment, follows a predefined line, detects obstacles, alerts the destination user, and returns to the starting point after delivery.

---

## 🎯 Objectives

- Develop an autonomous indoor medical supply delivery robot.
- Transport medicines between predefined hospital locations.
- Implement line-following navigation.
- Detect obstacles using IR sensing.
- Provide destination selection through the robot interface.
- Develop a web-based medicine request and order management system.
- Provide delivery and return notifications.
- Develop a low-cost prototype suitable for indoor hospital environments.

---

## ⚙️ Key Features

- 🤖 Autonomous line-following navigation
- 🏥 Multiple hospital destination selection
- 📦 Medicine storage compartment
- 🚧 IR-based obstacle detection
- 🔔 Buzzer-based arrival and obstacle notifications
